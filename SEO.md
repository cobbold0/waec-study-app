# WAEC Study App — SEO Strategy

## Objective

Acquire students through organic search for WAEC and examination-preparation queries.

The initial geographic focus is Ghana.

The architecture should allow expansion to other African markets later.

## Search Intent

Target several categories.

### Transactional

Examples:

- WAEC study app
- WAEC practice questions
- WAEC questions online
- WAEC study online
- WAEC exam preparation

### Subject

Examples:

- WAEC Mathematics
- WAEC English
- WAEC Integrated Science
- WAEC Social Studies
- WAEC Biology
- WAEC Chemistry
- WAEC Physics

### Informational

Examples:

- How to prepare for WAEC
- WAEC study tips
- How to study Mathematics for WAEC
- How to prepare for WASSCE
- Best way to practice for WAEC

Do not keyword-stuff pages.

## Initial Public Pages

Build useful pages around:

```text
/
/subjects
/subjects/mathematics
/subjects/english
/subjects/integrated-science
/subjects/social-studies
/waec-study
/waec-practice-questions
/waec-mathematics
/waec-english
/waec-study-tips
```

Only create subject pages when meaningful content exists.

## Subject Pages

A subject page should include:

- Subject introduction
- Topics
- Study guidance
- Practice CTA
- Useful explanations
- Related subjects
- Internal links

Do not create empty SEO pages.

## Content Strategy

Create genuinely useful educational content.

Potential articles:

- How to prepare for WAEC
- How to build a WAEC study timetable
- How to study Mathematics effectively
- How to improve English comprehension
- How to revise before an exam
- How to identify weak topics
- How to avoid common exam mistakes

Content should be written for students rather than search engines.

## Metadata

Every public page should have:

- Unique title
- Useful meta description
- Canonical URL
- Open Graph metadata
- Appropriate H1
- Logical H2/H3 hierarchy

## Structured Data

Use appropriate structured data where genuinely applicable.

Do not add fake:

- Ratings
- Reviews
- Statistics
- Authors
- Organizations
- Testimonials

## Internal Linking

Create a natural funnel:

```text
Study article
     ↓
Subject page
     ↓
Topic
     ↓
Practice
     ↓
Results
```

Cross-link related educational content.

## Indexing

Public educational pages can be indexed.

User-specific pages such as:

- Active sessions
- Personal progress
- Dashboards

should not be indexed.

## Sitemap

Create a dynamic/static sitemap appropriate to the framework.

Ensure important public pages are included.

## Robots

Configure robots correctly.

Do not accidentally block the entire website.

## Performance

SEO depends heavily on usability.

Prioritize:

- Mobile performance
- Fast content rendering
- Stable layouts
- Optimized images
- Minimal unnecessary JavaScript

## Ghana Focus

Use Ghana-specific context naturally.

Do not create hundreds of pages by swapping "Ghana" into identical text.

Later expansion can support other countries through genuinely localized content.

## SEO Principle

Search traffic is useful only when the page actually helps the student.

Prioritize:

**Useful content → trust → practice → returning student**

rather than:

**Keyword → thin page → advertisement**
